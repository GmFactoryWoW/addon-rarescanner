# RareScanner 3.3.5a Backport

A lightweight **World of Warcraft 3.3.5a** backport of [RareScanner](https://www.curseforge.com/wow/addons/rarescanner).

Based on **RareScanner WotLK 3.4.0.3** by **maqjav**:  
https://www.curseforge.com/wow/addons/rarescanner/files/4026370

## Changes

- Backported to **WoW 3.3.5a (Interface 30300)**.
- Reworked rare detection for 3.3.5a and added independent encounter/kill tracking.
- Added localized NPC data, levels, spawn coordinates and 3D models in alerts.
- Added rare spawn icons, tooltips and killed-state filtering to the **World Map**.
- Region maps display all spawns; continent/world maps display one pin per NPC.
- Added World Map quick options and compatibility with other map controls.
- Added **Interface > AddOns > RareScanner** settings for alerts, sound and map display.
- Added encounter/kill cache reset controls and `/rs` commands.
- Added **enUS/frFR localization** with enUS fallback.
- Removed unused code, media and unnecessary messages.
